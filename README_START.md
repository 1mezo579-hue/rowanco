# روانكو للمنظفات - نظام إدارة الكاشير والمخزن

هذا المشروع هو نسخة مخصصة من نظام POS لإدارة محلات المنظفات.

## كيفية البدء السريع:

1. **للمرة الأولى فقط**: قم بتشغيل ملف `تجهيز وتشغيل النظام.bat`. سيقوم بتثبيت كافة المكتبات وإعداد قاعدة البيانات ببيانات المنظفات.
2. **للاستخدام اليومي**: قم بتشغيل ملف `ابدأ النظام.bat`. سيقوم بفتح نافذة البرنامج تلقائياً.

## بيانات الدخول الافتراضية:
- **اسم المستخدم**: `admin`
- **كلمة المرور**: `102030` (تم ضبطها في ملف السكرت `prisma/seed.ts`)

## الميزات المضافة:
- أقسام منظفات جاهزة (مساحيق غسيل، مطهرات، مناديل، إلخ).
- منتجات منظفات واقعية بأسعار استرشادية.
- دعم الوزن (للمنظفات السايبة).
- نظام تقارير وفواتير كامل.
